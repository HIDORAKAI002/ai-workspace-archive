# Blog Post Writing Template

Create SEO-optimized, engaging blog posts with clear structure.

## Use Cases
- Writing blog articles
- SEO content creation
- Thought leadership posts
- Tutorial articles
- Company blog posts

## Template

```xml
<task>Write an SEO-optimized blog post</task>

<topic>[YOUR BLOG POST TOPIC]</topic>

<target_keyword>[PRIMARY SEO KEYWORD]</target_keyword>

<target_audience>
[Describe your readers: their role, expertise level, what they care about]
</target_audience>

<thinking>
Plan the post:
1. What's the main value/takeaway?
2. What questions does the reader have?
3. What examples will make this concrete?
4. What's the logical flow?
5. How do I hook them in the intro?
</thinking>

<requirements>
- Length: [word count, e.g., 1500-2000 words]
- Tone: [Professional / Casual / Technical / Conversational]
- Include: [Examples / Data / Case studies / Screenshots]
- SEO: Include target keyword in title, intro, one H2, and conclusion
- Structure: Clear H2/H3 headings every 300-400 words
</requirements>

<structure>
1. **Hook** - Start with problem, question, or surprising fact
2. **Promise** - Tell reader what they'll learn
3. **Body** - Main content with subheadings
4. **Examples** - Concrete use cases
5. **Takeaways** - Summary of key points
6. **CTA** - Clear next action

Each section should:
- Start with benefit/value
- Use concrete examples
- Break up text (bullet points, short paragraphs)
- Answer "so what?" for the reader
</structure>

<style_guidelines>
- Write like explaining to a friend
- Active voice (not passive)
- Short sentences (max 20 words)
- Break up paragraphs (max 3-4 lines)
- Use "you" to address reader
- NO jargon without explanation
- NO fluff phrases like "in today's digital landscape"
</style_guidelines>

<seo_requirements>
- Include target keyword naturally (don't stuff)
- Add 3-5 semantic keywords (related terms)
- Create compelling meta title (50-60 chars)
- Write meta description (150-160 chars)
- Suggest internal linking opportunities
- Include FAQ section for featured snippet
</seo_requirements>

<output_format>
1. **Meta Title** (50-60 characters)
2. **Meta Description** (150-160 characters)
3. **Main Title (H1)**
4. **Introduction** (hook + promise)
5. **Body** (with H2/H3 subheadings)
6. **Key Takeaways** (bullet points)
7. **FAQ Section** (3-5 Q&As)
8. **Conclusion + CTA**
9. **SEO Notes** (keyword placement, internal links)
</output_format>
```

## Example Usage

### Input
```xml
<task>Write an SEO-optimized blog post</task>

<topic>How to write effective prompts for AI coding assistants</topic>

<target_keyword>AI coding prompts</target_keyword>

<target_audience>
Software developers (junior to mid-level) who use ChatGPT/Claude for coding but aren't getting great results. They want practical tips they can use immediately.
</target_audience>

[Rest of template...]
```

### Expected Output Structure

```markdown
# Meta Title
AI Coding Prompts: 7 Tips to Get Better Code from ChatGPT & Claude

# Meta Description
Learn how to write AI coding prompts that actually work. 7 proven techniques to get better code from ChatGPT, Claude, and Copilot. Examples included.

# How to Write AI Coding Prompts That Actually Work

You copy-paste your code into ChatGPT. It spits out garbage. You try again. More garbage.

Sound familiar?

The problem isn't the AI. It's your prompt.

**In this post, you'll learn:**
- 7 techniques to write prompts that get usable code
- Real examples of bad vs. good prompts
- How to debug AI-generated code faster
- When to use AI (and when not to)

[Body content with examples, subheadings, etc...]

## Key Takeaways
- ✅ Be specific about input/output expectations
- ✅ Include context (language, framework, constraints)
- ✅ Ask for explanations, not just code
- ✅ Give examples of what you want
- ✅ Break complex tasks into steps

[FAQ, Conclusion, etc...]
```

## Variations

### For Technical Tutorials
```xml
<structure>
1. Problem statement
2. Prerequisites
3. Step-by-step instructions
4. Code examples
5. Troubleshooting common issues
6. Next steps
</structure>
```

### For List Posts ("10 Best...")
```xml
<structure>
1. Hook with bold claim
2. Each list item:
   - Name/title
   - Why it's on the list
   - When to use it
   - Example or screenshot
3. Comparison table
4. How to choose
5. Honorable mentions
</structure>
```
