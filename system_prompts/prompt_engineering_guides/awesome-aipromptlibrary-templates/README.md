## How to Use These Templates

### 1. Choose Your Template
Browse by category above and click the prompt that matches your use case.

### 2. Copy the Template
Each template is copy-paste ready. Look for the code block with the full prompt.

### 3. Replace Placeholders
Swap `[PLACEHOLDER TEXT]` with your actual content. Example:
```xml
<code>
[PASTE YOUR CODE HERE]
</code>
```
Becomes:
```xml
<code>
def hello_world():
    print("Hello")
</code>
```

### 4. Paste into Your AI Tool
Works with:
- ✅ Claude (3.5 Sonnet, 3 Opus, 3 Haiku)
- ✅ ChatGPT (GPT-4, GPT-4 Turbo, GPT-3.5)
- ✅ Google Gemini
- ✅ Other LLMs that support structured prompts

### 5. Iterate and Improve
Refine the output by:
- Adding more specific requirements
- Providing examples
- Adjusting tone/style parameters

## Best Practices

### ✅ Do This
- **Be specific** - The more context, the better the output
- **Use examples** - Show the AI what "good" looks like
- **Specify format** - Define exactly how you want the response structured
- **Add thinking tags** - Let AI reason through complex problems
- **Iterate** - Refine prompts based on initial outputs

### ❌ Avoid This
- **Vague requests** - "Make it better" doesn't work
- **No structure** - Walls of text confuse AI models
- **Generic terms** - Define what "professional" or "high quality" means
- **Skipping examples** - Examples dramatically improve results
- **One-shot approach** - Best prompts are refined over time
