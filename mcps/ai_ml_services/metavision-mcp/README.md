# MetaVision AI Studio — MCP Server

AI creative platform with 13 MCP tools. Compatible with Claude Desktop, Cursor, and any MCP client.

## Quick Start

Add to your MCP config:

```json
{
  "mcpServers": {
    "metavision": {
      "type": "http",
      "url": "https://metavision.click/mcp"
    }
  }
}
```

## Available Tools (13)

| Tool | Description |
|------|-------------|
| `generate_3d_model` | Generate 3D model from text/image (GLB/FBX/OBJ) |
| `analyze_gcode` | Analyze CNC G-code, detect errors, estimate time |
| `generate_story` | AI story generation in 10 genres |
| `interior_design_profile` | AI interior design based on personality |
| `search_3d_models` | Search 10K+ free 3D models library |
| `get_space_wallpaper` | Get 4K space wallpapers |
| `get_deals` | Real-time coupons from Amazon, eBay, Nike and more |
| `calculate` | Math calculations with sqrt, sin, cos, log support |
| `convert_units` | Convert length, weight, temperature, volume, speed |
| `summarize_text` | AI text summarization |
| `translate_text` | AI translation to any language |
| `get_random_fact` | Random interesting facts by topic |
| `generate_qr_code` | Generate QR codes from text or URL |
