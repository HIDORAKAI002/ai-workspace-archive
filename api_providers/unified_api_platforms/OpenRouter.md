## API Endpoint
```
https://openrouter.ai/api/v1/chat/completions
```

## Access & Limits
| | |
|---|---|
| **Free Tier** | ~50 requests/day on free models (25+ free models) |
| **Rate Limits** | Free: 20 RPM, 200 RPD |
| **Models Count** | 300+ from 60+ providers |
| **Platform Fee** | 5.5% on credit purchases |
| **BYOK** | 1M free requests/month, then 5% fee |

## Key Features
- Single API endpoint
- Automatic failover
- Usage analytics
- OpenAI-compatible API
